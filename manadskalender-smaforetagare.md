# Månadskalender för svenska småföretagare

En översikt över återkommande deadlines hos Skatteverket och Bolagsverket för
dig som driver enskild firma eller aktiebolag med kalenderår som räkenskapsår.

> **Viktigt:** Exakta datum kan flyttas om de infaller på en helg, och vissa
> frister styrs av ditt företags räkenskapsår eller redovisningsperiod för
> moms. Kontrollera alltid aktuellt datum på [skatteverket.se](https://www.skatteverket.se)
> och [bolagsverket.se](https://www.bolagsverket.se) inför varje period.

## Återkommande varje månad

| Datum | Vad |
| --- | --- |
| Den 12:e i månaden (den 17:e i januari och augusti) | Moms- och arbetsgivardeklaration samt inbetalning av preliminärskatt (F-skatt), för dig som redovisar moms månadsvis |

## Månad för månad

| Månad | Frist | Gäller |
| --- | --- | --- |
| Januari | 31 januari | Kontrolluppgifter till anställda ska vara utskickade |
| Februari | 12 februari | Momsdeklaration för kvartal 4 (för dig som redovisar moms kvartalsvis) |
| Mars | - | Förbered bokslut inför årsredovisning/inkomstdeklaration |
| April | - | Bolagsstämma bör hållas senast inom 6 månader från räkenskapsårets slut |
| Maj | Början av maj (exakt datum varierar per år) | Inkomstdeklaration 1 med NE-bilaga (enskild firma) |
| Juni | - | Sommaruppehåll - inga särskilda deadlines |
| Juli | 1-3 juli (dagen varierar) | Inkomstdeklaration 2 (aktiebolag med kalenderårsbokslut) |
|  | 31 juli | Sista dag att skicka in årsredovisning till Bolagsverket (senast 7 månader efter räkenskapsårets slut) |
| Augusti | 17 augusti | Momsdeklaration för kvartal 2 (kvartalsredovisning) |
| September | - | Halvårsavstämning av bokföring inför hösten |
| Oktober | - | Se över preliminärskatten inför årsskiftet |
| November | 12 november | Momsdeklaration för kvartal 3 (kvartalsredovisning) |
| December | - | Sista chansen för årets skattemässiga dispositioner (t.ex. periodiseringsfond) |

## Årsvis moms (omsättning under 1 miljon kr)

Redovisas samtidigt som inkomstdeklarationen - se maj (enskild firma) eller
juli (aktiebolag) ovan.

## Bra att veta

- **Enskild firma**: räkenskapsåret är alltid kalenderår (1 januari-31 december).
- **Aktiebolag**: kan välja brutet räkenskapsår - flytta då motsvarande frister ovan.
- Anmäl redovisningsperiod för moms (månad, kvartal eller år) hos Skatteverket
  - det styr vilka datum som gäller för just ditt företag.
